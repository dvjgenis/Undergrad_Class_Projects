# Telemetry & Repair Efficiency

Scripts to analyze:

- **Repair Efficiency** — Time from upload to performance-ready vs baseline (notation editor + raw GPT-4 MIDI)
- **CSI** — Creativity Support Index (Tchemeube et al., 2025)
- **SUS** — System Usability Scale (adapted for interpretability and agency)
- **NPS** — Net Promoter Score (adoption likelihood)

Place survey data and timing logs here. Use `make eval-telemetry` to run analysis.
